LIKENESS / DESIGN CONTROL
The approved Girl Explorer human-character foundation was developed from the actual likeness of Serenity Gray. The approved Boy Explorer human-character foundation was developed from the actual likeness of Ewan Gray. Skin-tone variants are appearance options built from those same approved FQC character foundations; they are not intended to represent different named identities.

These Explorer designs are the baseline human-character reference for future Family Quest Center packs. Pack themes may change clothing, equipment, hairstyle, pose, and accessories while retaining the approved FQC visual language and likeness foundation.

The original family reference photograph is source documentation only and is not included in this distributable pack.
