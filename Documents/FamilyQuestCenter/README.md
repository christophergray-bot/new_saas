# Family Quest Center

Family Quest Center is a Flask-based family responsibility and adventure platform that turns chores into quests and supports adventures, rewards, achievements, Explorer profiles, content packs, and interactive Quest Books.

**Current reviewed build:** `1.7.0-rc1`  
**Status:** Release candidate / active pre-production testing

## Core stack
- Python / Flask
- Jinja templates
- SQLite for current local/staging use
- Railway staging/deployment support
- Stripe subscription integration
- Email-based account recovery
- Family-scoped content packs and Quest Books

See `README.txt` for setup notes and `docs/RELEASE_NOTES_1.7.0-RC1.md` for this build.
