# Family Quest Center Local User Guide

## Getting started

Start the application, create the first family account, create a Parent PIN, and
complete family setup. The first account becomes the family Owner.

## Parent tools

Parents can create children, Quests, recurring Missions, Adventures, Rewards,
Achievements, and Family Challenges. Administrative tools are protected by the
Parent PIN when the computer is shared.

## Child experience

Children select their profile from the family dashboard to review missions,
complete work, follow Adventures, request Rewards, and view progress.

## Account and Parent PIN recovery

A signed-in Owner or Parent can reset a forgotten Parent PIN from **My Profile**
by confirming the account password. This reset does not require email.

The local edition does not provide email-based account-password recovery. Keep
regular tested backups. Hosted password reset will be added after production
email delivery is configured.

## Content Packs

Open **Content Pack Manager** to view bundled packs. Packs may be installed,
archived, and restored. The built-in Default Family Pack remains protected from
whole-pack archiving, although its individual content may be archived normally.

## Backups

Create backups before major configuration changes and periodically test that a
backup can be restored. See `docs/developer/BACKUP_RESTORE_GUIDE.md`.
